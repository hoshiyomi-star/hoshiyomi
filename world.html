
YOUR WORLD

世界を描く

頭の中にある景色や物語、
大切な記憶や好きなものをもとに、
あなたの世界を一枚の作品として形にします。

```

まだ言葉になっていないイメージでも大丈夫です。
あなたの中にある「こういう世界が好き」という感覚を、
一緒に整理しながら作品へと形にしていきます。

```

CONTENT

描くものについて

あなたの世界を形作るものをもとに、
一枚の作品として構成していきます。

```
01｜MEMORY

記憶・思い出

忘れたくない景色や出来事、
大切な思い出などを
作品の中に取り入れます。

02｜IMAGE

想像する世界

頭の中にある景色や物語、
想像している世界を
一枚の作品として形にします。

03｜FAVORITE

好きなもの

好きな色、場所、季節、植物など、
あなたを表すものを
作品の中へ重ねていきます。

04｜STORY

物語・世界観

設定や物語、雰囲気など、
あなたが大切にしている世界観を
一枚の中にまとめます。

```

PROCESS

制作の流れ

あなたの中にあるイメージを、
少しずつ作品へと形にしていきます。

```

01｜お話を聞く

描きたい世界や好きなもの、
思い出などをお聞きします。

02｜イメージを整理する

お聞きした内容をもとに、
構図や世界観を整理します。

03｜ラフ制作

作品全体の構図や雰囲気を確認しながら、
ラフを制作します。

04｜完成

ラフ確定後、細部まで描き込み、
一枚の作品として仕上げます。

```
